Auto-Sort Client Details

Paste a raw message from a client (however messy — a Messenger chat, an email, a list) and this will try to detect and sort the details into the right fields. Always double-check the results before using them — this uses pattern-matching, not true understanding, so it won't catch everything.

Works best with full sentences containing dates, times, venue names, and addresses — the more natural the message, the better it can guess.
